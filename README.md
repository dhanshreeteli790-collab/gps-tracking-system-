# 📍 GPS Tracking System

## 📖 About Project
This is a real-time GPS tracking system where users can share their live location and admin can monitor multiple users on a map.


## 🚀 Features
- 📌 Live location tracking
- 👤 User login system
- 🧑‍💻 Admin dashboard
- 🗺️ Map integration (Leaflet)
- 📊 Location history tracking


## 🛠️ Technologies Used
- Node.js
- Express.js
- MySQL
- Socket.io
- HTML, CSS, JavaScript


## ⚙️ Installation & Setup

1. Clone the repository
2. Run this command:
   npm install
3. Start server:
   node app.js
4. Open in browser:
   http://localhost:3000


## Project Structure
- public/ → frontend JS & CSS
- views/ → UI pages (EJS)
- app.js → main backend file
